# Source code for sweepr

Sweepr is free software licensed under GPL-3.0-or-later.

The complete corresponding source code, build instructions, and version
history are available at:

https://github.com/Chamudu/sweepr

For a released binary, use the Git tag matching the version printed by:

```sh
sweepr --version
```

GitHub releases also include a source archive for the tagged revision. Build
instructions are in `README.md` and `docs/GETTING_STARTED.md`.
