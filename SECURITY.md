# Security policy

## Supported versions

Before the first stable release, security fixes are made on the latest code on
the `master` branch. This table will be replaced with supported release lines
after `v1.0.0`.

## Reporting a vulnerability

Do not publish deletion bypasses, path-traversal issues, or other exploitable
details in a public issue. Use the repository's private **Report a
vulnerability** form under the GitHub Security tab:

https://github.com/Chamudu/sweepr/security/advisories/new

Include the affected platform, sweepr version or commit, reproduction steps,
and the potential impact. If private vulnerability reporting is temporarily
unavailable, open a public issue asking the maintainer for a private contact
method without including sensitive details.

Ordinary non-security bugs can use the public issue tracker.
